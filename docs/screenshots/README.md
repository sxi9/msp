127.0.0.1:18091 with a fresh SQLite file, an admin user, one client org ("Acme Dental") and one
enrollment token created through the CLI (`user add`, `org add`, `token new`), and the real
`bin/msp-agent` enrolled on the Linux build host (hostname `vm`, sync interval 2 s). Captured with
Playwright (chromium, deviceScaleFactor 2, light theme) as full-page images; every page exists at
desktop width (1280 px, `*-desktop.png`) and phone width (400 px, `*-phone.png`). At phone width
`document.documentElement.scrollWidth` was 400 on every page, i.e. no horizontal scroll.

screenshot; the database it belonged to was deleted after the run.

Screenshots 24 and 25 (`24-notifications-settings-*`, `25-notification-deliveries-*`) come from an eighth run
(NS1 alert notifications, fresh database on a free port, deleted afterwards, admin / org / token from the CLI)
with the real Linux agent `vm` enrolled under **Acme Dental** at a 2 s interval. This is the live-browser proof
of the NS1 dashboard with the notification senders running for real against local listeners: an **Ops email**
channel pointed at a local fake SMTP server and an **Ops Slack** webhook channel pointed at a local HTTP
listener. The Slack channel reaches the listener through an `/etc/hosts` name (`slack-hook.msptest.internal`)
that passes the deterministic, no-DNS webhook SSRF guard — the DNS-rebinding residual documented in
docs/SECURITY.md section 12 — so no loopback IP literal is stored. **Send test** on both channels landed `sent`
(the fake SMTP received the email, the listener received the Slack `{"text":…}` post), and stopping the agent
opened an `offline` alert that the active maintenance window **suppressed**. 24 is the Notifications settings
page (two channels, the routing rule, the active-now window); 25 is the Delivery log showing the two sent rows
and the suppressed row. The `/etc/hosts` entry was removed and the live database deleted afterwards. The label
banner was prepended to the page body before each capture and at phone width `scrollWidth` was 400 on both
pages.
